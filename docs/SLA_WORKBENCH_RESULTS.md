# v0.9.0 SLA暂停补偿与风险工作台

日期：2026-11-13；本机独立MySQL/Redis和Java/Vue容器，Python源码未改动，无生产部署。

## 交付功能

多轮客户等待按微秒累计，恢复处理/关闭时顺延解决截止，首次响应截止不变；事务失败、过期版本和并发客户操作不能重复补偿。既有等待从迁移时刻开始记录，不伪造旧时长。风险队列按原工单范围分页、检索和筛选超时/30分钟临期/等待客户，显示统一asOf与范围计数；只读链接交回原工单权限和处理流程。桌面与手机均可进入，详情解释暂停和已累计时长，刷新失败清除旧事实。

## 实际验证

- Java clean verify：101项通过，失败/错误/跳过0，真实MySQL/Redis。新增6项覆盖多轮暂停、先超时后等待、时钟倒退、事务回滚、并发一次性、范围/字面搜索、时间边界及分页。
- Vue类型/生产构建通过；Playwright35项通过，包含实际App的390px工具栏入口、风险筛选/分页/工单跳转、客户无内部请求、失败清旧结果及累计等待说明。Python未改动，真实向量40项结果沿用v0.8，同次PR/主分支CI重新执行既有AI合同检查。
- 独立审查指出初版手机入口被侧栏隐藏；补常驻工具栏入口并先复现失败、后通过新增导航测试，复核确认修复。

- API/Web源码镜像构建与健康启动；桌面和390px手机截图已检查，未发现横向溢出或页面错误。
