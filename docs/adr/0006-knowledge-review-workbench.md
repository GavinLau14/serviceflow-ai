# ADR 0006：知识审核的查询快照与审核记录

状态：已实现。

知识审核工作台使用独立组件与服务端分页。工单权限是唯一授权来源：客服按当前受派工单、主管按当前团队、管理员全局，列表/筛选计数/全部待审计数共享SQL范围条件。读取使用显式REPEATABLE_READ，让当前响应中的计数、来源和条目来自同一快照。关键词按标题/正文做LOCATE字面量匹配，AI语义检索独立管理。

审核继续采用先锁来源工单、再锁知识条目的顺序。只有DRAFT可以UPDATE审核结论、审核人、意见与时间；事件和业务审计共享事务。相同结论/规范化意见重试返回原记录；不同结论或意见409，防止第二位审核人覆盖第一位的处理依据。退回必须提供理由，通过可选填。旧历史意见NULL保留未知，不能凭新版本补造。

工作台在审核成功后重新查询服务端状态，不在前端模拟待审总数。当前页变空时回到有效页；请求失败清除上一筛选的正文。手机使用队列/详情切换，来源工单仍交由已有工单权限检查。修正内容通过来源工单另建草稿，原记录保留；暂不提供显式父版本关系和文本对比。

业务知识的审核与AI语料发布继续分离，本轮不新增任何自动索引调用。将来发布到客户可检索语料时，需要独立的脱敏、授权、版本和撤回设计。
