# ADR 0008：可核验的索引状态与显式恢复

状态：已实现（v0.8.0）。

SYNCED 代表最近一次写入回执，不代表持续健康，也不能发现备份恢复或人工误删造成的点丢失。管理员可对已有公开版本执行真实点核验，MISSING/INVALID 令该版本 FAILED 并停止引用；UNAVAILABLE 单独记录，不把网络故障误报为物理丢失，也不宣称健康。

Python 核验不加载 embedding，直接读取确定性 point ID，检查 collection 的384维 cosine 配置、公开快照各字段和模型标识，以及向量长度和有限数值。核验不证明向量的语义质量，索引修复仍使用真实 MiniLM 重新生成。

管理员显式确认修复时，在短事务中先锁来源工单，再预留 operation_revision 并转 PENDING，同时写修复审计。事务提交后调用 Python，只有仍 ACTIVE 且 revision 相同的回执才能写最终状态。每次核验也递增 revision，防止旧核验结果覆盖较新的修复；已撤回永远不能借修复恢复。旧版本清理沿用幂等撤回 API。

当前采用按版本人工核验/修复，不引入新队列或自动轮询。状态面板服务端分页，汇总和列表使用 REPEATABLE_READ 同一快照；只管理员可访问。客户端在角色变化和卸载后丢弃旧请求，失败刷新清除旧行。面板与发布详情的刷新互相通知，避免同次操作后留下过时显示。

没有定期核验、自动重试、故障告警或永久可用保证。进程在 PENDING 时退出可人工修复；物理向量清理仍为最佳努力。多实例的网络请求可能重复，但不可变文档与 revision 条件防止迟到写入数据库状态；向量存储与数据库不具备跨服务原子事务。
