# ADR 0007：知识公开授权与索引分离

状态：已实现（v0.7.0）。

审核通过只表示内部知识可用，不代表向全部客户公开。只有管理员可以另填脱敏标题与摘要，并分别确认脱敏和全体登录客户可见。内部正文、审核意见、工单及员工标识不会自动复制到公开文档。脱敏由人负责，系统不承诺自动识别所有隐私。

MySQL 保存不可变 UUID/版本快照，ACTIVE 与 SYNCED 同时成立才可被引用。全局 guard 行序列化发布上限和版本分配；每项知识最多一个 ACTIVE 版本，当前演示最多 50 项，元数据历史最多返回 20 个版本。替换先撤回旧版再创建新版；索引失败不恢复旧版，需重试或重新发布。

网络调用在数据库事务之外。授权先提交，Python 使用真实多语言 MiniLM 向独立 Qdrant collection 写入；确认回执后更新索引状态。撤回先提交禁止引用，再尽力删除向量。迟到的索引回执不能恢复授权，并触发补偿清理。清理失败可重试，物理向量存在不代表可引用。

Java 每次请求只传有效公开快照白名单，Python 按 ID 过滤并核对全部字段、版本及 embedding 模型身份。Java 在回答落库及提案执行事务内对引用行加共享锁，复核仍有效且内容一致；撤回与最终授权有确定的串行顺序。任何动态引用不一致时整条回答降级，不保留可能使用旧来源生成的建议。

历史读取同样重新校验，撤回后不向 API 返回旧建议。已完成工单不被撤销，人工接管仍可使用原客户消息。已经展示、已发送给模型或在撤回事务前完成最终校验的响应无法收回。原始 AI 日志保留于数据库，界面/API 隐藏不等于物理删除；不承诺第三方模型端数据擦除。生产前需补充保留策略、异步索引恢复及更大规模分页检索。
