# M3 workbench UI redesign

用户表示前端不满意，已发出可选风格澄清，独立后端先推进。当前未收到具体方向时的工程假设：高效、精致的客服工具。

观察：M2纵向卡片队列+固定空白说明区只利用一半主区；桌面工单多时详情随整页滚动；主要操作和基础信息缺乏明确分层；窄侧栏只有单一入口，没有支撑真实协作模块。

改为石墨深色导航、明亮主区、克制蓝色动作、标准数据表格。无选择时队列使用全宽，选择后紧凑列表+宽详情。过滤器、数量、分页形成队列工具栏；详情独立滚动；通知/知识库是实际路由状态并提供空/错/加载。客户仍保留显式确认和AI引用。关闭装饰口号，不加入没有来源的统计数字。字体、留白、边界和键盘焦点统一。

目标保留：工作日明亮办公室下长期阅读，角色范围清晰；桌面与390px均可用；旧M1/M2业务自动化不因换皮失效。无外部图片装饰，图标使用已有ElementPlus图标库。
