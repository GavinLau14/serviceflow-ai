# M2 design and implementation plan

User authorized continuation and engineering choices. Preserve independent repository, no remote push. Java remains sole business writer.

Contract: Java POST /api/ai/assist {message} customer-only → {id,mode,intent,answer,confidence,handoff,citations:[{id,title,source,text,score}],proposal:null|{title,description,category,priority},status,ticketId}. GET /api/ai/runs (own last20); POST /api/ai/runs/{id}/execute {confirmed:true} → Ticket. Persist proposal server-side; owner check + row lock + existing ticketId makes execution idempotent. Expire unexecuted proposals in 30 minutes. Never accept proposal fields in execute request. POST assist to Python /assist with X-Service-Token, body {message}. GET Python /health returns only readiness modes, no secrets.

Python contract: {mode:'rag'|'retrieval_only'|'disabled'|'error',intent,answer,confidence [0,1],handoff:boolean,citations:[{id,title,source,text,score}],proposal:null|{title,description,category:'DEVICE'|'APPLIANCE',priority:'NORMAL'|'HIGH'} }. LangGraph nodes retrieve→decide→validate. Real FastEmbed multilingual model + Qdrant. Configurable OpenAI-compatible LLM structured extraction and tool_calls, restricted create_ticket tool; citations must resolve to retrieved IDs. No LLM fallback pretending inference. Without key real embedding retrieval can display extracts only (retrieval_only), no inferred proposal. LLM failure/low evidence → handoff, no invented policy/status. Admin-only Java reindex proxy → Python /index bundled demonstration KB. Python has NO business DB credentials. Index management bounded, authenticated, model/dimension versioned collection; no arbitrary remote document URLs.

Tasks:
- [x] Python service/tests: typed schemas, dependencies, real embedding/index/query, LangGraph gates, restricted model tool proposal, robust unavailable behavior; pytest first.
- [x] Java integration/tests: internal HTTP client timeout, validate response, run log, owner-scoped history, explicit confirmation, idempotency and transactional execution; migrations and real MySQL tests.
- [x] Vue customer assist drawer: citations, mode/hand-off, pending draft confirmation, history and created ticket; admin index action; no fabricated success.
- [x] Real embedding + Qdrant smoke; fake model contract tests separately labeled. Update CI, scripts, .env.example, docs, actual results; run M1 regression and independent review; local M2 commit.

Risks: model downloads may fail, no API key currently provided, semantic score is not calibrated probability, KB examples are not real customer policies. Real model testing must be reported separately from deterministic fake HTTP responses.
