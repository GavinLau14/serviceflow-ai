# 账号密码与会话失效

GitHub v0.4.1 已公开发布，首次远程CI三项任务通过（run 43181146777）。后续作为独立账号模块开发，不修改用户当前演示密码。

设计：POST /api/auth/password，登录用户提供当前密码、新密码、confirmed=true。新密码至少12个Unicode码点且不超过72个UTF-8字节，禁止与当前密码相同。账号行锁内验证当前密码并更新 BCrypt 哈希及 credential_version；会话值绑定账号凭据版本，每次鉴权比较数据库当前版本，改密后全部旧会话失效。现有旧格式会话只在账号版本0时兼容；无需对Redis执行全库扫描，也不依赖数据库/Redis跨库事务。

新的版本字段不对API序列化。只改本人，不接收userId。当前会话改密成功后由前端清理登录态，明确要求重新登录；错误密码或数据库更新失败不修改任何会话。并发改密只有一个旧密码请求能成功，旧账号快照在改密后签发的token也会被拒绝。

步骤：
1. 先写集成测试，观察端点缺失失败。
2. 实现 V6、UserMapper、PasswordService、SessionService版本绑定和REST；测试现有会话兼容、并发/回滚及旧快照失效。
3. 新增账号安全抽屉，沿用现有系统控件、移动端avatar入口；密码二次输入与明确确认，不显示或记录密码。
4. Java全量、前端类型/构建、浏览器、Docker更新和既有账号只读验证。通过功能分支/PR远程CI再集成与版本记录。
