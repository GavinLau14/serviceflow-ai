# v0.10.0 AI运行观测验证

日期：2026-11-14。本机独立MySQL/Redis、Java/Vue与既有Python/Qdrant容器，无生产部署。

## 交付功能

管理员桌面/手机“AI运行”：统计窗口、当时模式、关联工单筛选与服务端分页；窗口汇总、记录平均耗时、原始引用/提案元数据及工单跳转。记录与健康分别加载、失败分别清空，账号/角色切换后丢弃旧请求。全局接口只向ADMIN开放，不返回客户身份、原消息、回答或引用正文。

健康核验区分NOT_CONFIGURED/REACHABLE/UNAVAILABLE，展示服务报告模式与配置标记。整体等待3秒、响应4096字节订阅上限，未知/矛盾字段及上游错误脱敏。核验不调用真实语言模型，也不验证服务鉴权或问答质量。

## 实际验证

- Java clean verify：109项通过，失败/错误/跳过0；真实MySQL/Redis。新增8项覆盖角色、窗口上下界、分页/过滤/汇总、损坏日志、固定模式、隐私白名单、未配置、慢headers/慢body和超大响应。
- Vue类型检查/生产构建通过；Playwright45项通过。新增6项含时间/模式/关联筛选、分页/工单跳转、健康独立失败、旧结果清空、非管理员无查询、实际App手机入口，以及账号/角色切换后的双请求门闩。
- 初始UI红测时开发服务器未启动，恢复后确认组件缺失失败；实现后筛选测试曾因Element Plus的listbox与combobox共享标签、输入框被占位层遮挡而失败。改为定位真实select容器并等待控件可用后重跑，不使用强制点击。
- 真实MySQL发现尾空格模式普通比较为真，新增红测复现后用CAST AS BINARY严格匹配；聚焦测试及全量通过。
- API/Web源码镜像构建并健康启动，Flyway V11成功。Python源码未修改，真实向量40项沿用v0.8；远程CI重新运行既有AI合同。
- 真实运行台读取近7天19条日志、6条工单关联；健康报告retrieval_only、向量就绪、语言模型未配置。客户/客服/主管对两个全局接口均403，输出仅8个允许的记录字段。管理员手机打开关联工单30，主管手机无全局入口；未新增演示工单或伪造运行日志。
- 桌面与390px手机截图已检查，无横向溢出或页面错误。独立只读审查未发现重要缺陷，并建议补强的迟到响应验证已加入。
